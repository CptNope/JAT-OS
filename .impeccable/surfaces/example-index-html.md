# Surface brief: JAT OS shell example (example/index.html)

Scope: interactive prototype of the JAT OS desktop shell, entered from a demo WordPress-style site. Mode: Operate. Related surfaces: brand book (brandbook/index.html, Read) and overview (index.html, Read/Persuade-light) share the same world.

Audience and job: guests and signed-in makers launching the Craft PWAs (VectorCraft, PhotoCraft, FigCraft, PdfCraft), multitasking in windows, switching shell styles, and returning to the website.

Constraints: no fake functionality; concept-only features are labeled; apps launch embedded (same-origin GitHub Pages iframe) or externally; no Apple/Microsoft/Google names or marks in UI.

## Direction contract
THESIS: The category standard, played straight at flagship craft: one JAT OS token and component system expressed through four switchable shell styles (Dock default, Taskbar, Shelf, Activities). Refuses the half-built "web desktop" toy: every control works or is labeled concept.
OWN-WORLD: Cool neutral greys, one JAT Blue accent, Inter UI type with tabular numerals, JetBrains Mono only for paths and versions. Original stacked-windows mark. Selective translucency only on bars, dock and menus over wallpaper, with solid fallbacks. Authored SVG wallpapers and app icons.
STORY: The visitor sees a normal site, toggles into OS mode, launches a Craft app, arranges windows, switches style in Settings, exits back to the untouched site.
FIRST VIEWPORT: Dock style: slim top menu bar (JAT mark, active app name, clock, quick settings), wallpaper desktop with the app shortcuts in a column at the right (Dock convention; the other styles place them at left), centered floating dock at bottom with Launcher first, pinned Craft apps, running indicators; a welcome window centered on first launch.
FORM: Category standard (canon), chosen by the user over the assigned swatch direction (list position 3) and Transit pick; seed key 4693b33a (degraded roll, no challengers).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
